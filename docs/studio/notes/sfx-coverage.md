# SFX override coverage

Status 2026-11-14. Covers the 23 original effect IDs and the 7 pack-only
events. Packs are private and live outside the repo; this note names them but
holds no audio.

## Totals

| | Count | IDs |
|---|---|---|
| Overridden in pack-v1 | 24 | 17 originals + 7 pack events |
| Newly filled in pack-v2 | 6 | phone-pickup, weapon-1, weapon-2, weapon-3, weapon-4, police-siren |
| Still open (no override) | 0 | |

Caveats that stay open:

- weapon-2 has no call site, so the game never plays it. Its override exists
  but nothing can hear it in play.
- weapon-2 and police-siren are restorations of the originals only (band
  limit, level match, dither). No CC0 or approved recording fits: the PC3
  siren clips are short chirps (1.05 s and 0.69 s), not a 7.5 s wail.
- kitchen-busy (-27.7 LUFS) and kitchen-idle (-29.7 LUFS) are under the bed
  window of -23 +/- 2 LU. Both levels were accepted by the coordinator.
- The hidden `[sfx-pack-v2]` test is written and compiles, but this lane may
  not run tests; it has not been run. The level figures below are an offline
  prediction from the same files, not test output.

## Sources and licences

- **PC3**: Pizza Connection 3 (Gentlymad Studios / Assemble Entertainment,
  2018). Clips the owner had already extracted; owner-approved private reuse,
  not redistributable.
- **Authored**: synthesized standard signals made for this project (ITU-T Q.23
  DTMF; North American ringback 440+480 Hz).
- **Kenney**: kenney.nl, CC0 1.0. The licence file is kept with each source.
- **1994 original**: the owner's own copy of Pizza Tycoon, exported to
  `sfx-masters/original`. pack-v2 derivatives start from these.
- **Procedural**: layers generated by the pack-v2 builder (seeded noise and
  sine), authored here.

No Barro's Pizza material is used. The Tapper sources hold music only.

Run the hidden one with:

    PLEGACY_TEST_GAME_PATH=<game> PLEGACY_SFX_PACK=<pack-v2> test_plegacy "[sfx-pack-v2]"

`tools/audio/loudness_check.py` on the pack folder. Of 112 sounds, all pass
except the two kitchen beds noted above. The test checks a coarser level
match, through the mixer.
